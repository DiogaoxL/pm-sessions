# ADR — Architecture Decision Records

Cada arquivo desta pasta representa uma decisão arquitetural permanente do projeto.

Fluxo:

Nova decisão

↓

Discussão

↓

Architecture Decisions

↓

ADR Individual

↓

Aprovado

↓

Implementado

↓

Nunca apagar.

Caso uma decisão seja substituída, seu status deverá ser alterado para "Superseded", mantendo seu histórico.
