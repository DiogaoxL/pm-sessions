# Feature 001 — Public Scheduling

[← Voltar para Índice Mestre](../README.md)

---

## Visão Geral

Esta feature provê um link público onde candidatos externos podem escolher horários e se agendar de forma descentralizada em sessões ativas do recrutamento.

## Objetivo

Centralizar a alocação de sessões e automatizar a criação de eventos e links do Meet no Google Calendar sem vazamento de privacidade ou conflito de concorrência.

## Fluxo

O candidato acessa o link ➔ Escolhe data e horário ➔ Preenche Nome, E-mail e Telefone ➔ Confirma reserva ➔ Recebe convite no e-mail.
