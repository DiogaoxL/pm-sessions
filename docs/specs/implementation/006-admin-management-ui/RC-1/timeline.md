# Cronograma e Linha do Tempo — Feature 006

## Ordem de Implementação Recomendada

1. **Task 01: Setup de Feedbacks e Componentes Globais (Toasts)**
   - _Justificativa_: Estabelece a infraestrutura comum de notificações necessária para exibir feedback das Server Actions nas tasks seguintes.
2. **Task 02: Modais de Criação e Edição de Time Slots**
   - _Justificativa_: Permite a inserção básica de horários na agenda para que possamos testar as telas administrativas.
3. **Task 03: Fechamento e Remoção de Time Slots com Validação**
   - _Justificativa_: Acopla diálogos de confirmação destrutiva e regras visuais de bloqueio de exclusão em slots com candidatos confirmados.
4. **Task 04: Controle de Sessions: Exibição de Vagas e Ajuste de Capacidade**
   - _Justificativa_: Expõe a quantidade de vagas ocupadas e permite expandir os limites de vagas da sala.
5. **Task 05: Modificações de Candidatos: Dialog e Dropdown**
   - _Justificativa_: Completa o fluxo administrativo permitindo reorganizar ou cancelar participantes de entrevistas a partir de ações diretas na tela.
