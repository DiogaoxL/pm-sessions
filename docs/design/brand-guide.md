# Brand Guide

> Guia oficial da identidade visual do PM Sessions.

---

# Objetivo

O PM Sessions utiliza a identidade institucional da Pulse como base, porém adaptada para um produto SaaS voltado à produtividade.

O objetivo deste guia é garantir consistência visual durante toda a evolução do sistema.

Este documento define:

- identidade visual;
- direção estética;
- cores;
- tipografia;
- componentes;
- iconografia;
- espaçamentos;
- comportamento visual.

---

# Personalidade do Produto

O PM Sessions deve transmitir:

- confiança;
- organização;
- simplicidade;
- velocidade;
- profissionalismo;
- acolhimento.

O sistema deve parecer uma ferramenta moderna de trabalho, e não um website institucional.

---

# Público

Usuários principais:

- Equipe administrativa da Pulse;
- Mentores;
- Organizadores de processos seletivos.

Usuários secundários:

- Candidatos (fluxo público extremamente simples).

---

# Design Direction

A identidade visual seguirá uma abordagem inspirada em produtos SaaS modernos.

Princípios:

- Dark Mode como padrão;
- interface limpa;
- poucos elementos decorativos;
- foco em produtividade;
- alta legibilidade;
- alto contraste;
- muito espaço em branco (ou espaço negativo);
- poucos elementos por tela.

Evitar:

- excesso de cores;
- excesso de bordas;
- excesso de sombras;
- elementos puramente decorativos.

---

# Identidade da Marca

A identidade da Pulse será preservada através de:

- logotipo;
- cores institucionais;
- tipografia;
- tom de comunicação.

O layout, entretanto, será adaptado para um ambiente operacional.

# Tipografia

Fonte oficial:

Poppins

Pesos utilizados:

- 300
- 400
- 500
- 600
- 700

Jamais utilizar outra família tipográfica.

---

# Dark Theme

O MVP será desenvolvido exclusivamente em Dark Mode.

Características:

- fundo escuro;
- superfícies elevadas;
- contraste elevado;
- textos claros;
- poucas cores saturadas.

O Light Theme poderá ser implementado futuramente.

---

# Layout

A interface deverá priorizar:

- grandes áreas livres;
- alinhamento consistente;
- grids simples;
- componentes bem espaçados.

---

# Bordas

Padrão:

16px

Cards maiores:

20~24px

Campos:

14~16px

---

# Sombras

Utilizar sombras discretas.

Jamais utilizar sombras pesadas.

Objetivo:

Separação de planos.

Nunca decoração.

---

# Componentes

Todos os componentes seguirão o Design System.

Principais:

- Button
- Input
- Select
- Date Picker
- Calendar
- Card
- Modal
- Drawer
- Badge
- Avatar
- Tooltip
- Table
- Empty State
- Loading
- Skeleton

---

# Botões

Primário

Azul institucional.

Secundário

Outline.

Terciário

Ghost.

Danger

Vermelho.

---

# Campos

Todos os formulários deverão utilizar:

- Label
- Hint
- Mensagem de erro
- Placeholder
- Estado Disabled
- Estado Loading

---

# Cards

Os cards serão o principal elemento estrutural do sistema.

Características:

- cantos arredondados;
- padding amplo;
- sombra suave;
- conteúdo organizado.

---

# Ícones

Biblioteca oficial:

Lucide React

Regras:

- espessura uniforme;
- tamanho consistente;
- sempre acompanhando texto quando necessário.

---

# Ilustrações

O MVP não utilizará ilustrações.

Priorizar:

- dados;
- informação;
- produtividade.

---

# Animações

Animações rápidas.

Duração sugerida:

150–250ms

Evitar animações chamativas.

---

# Responsividade

Desktop

Prioridade máxima.

Tablet

Suportado.

Mobile

Suporte funcional.

---

# Acessibilidade

Todos os componentes deverão possuir:

- contraste adequado;
- navegação por teclado;
- foco visível;
- labels acessíveis;
- suporte a leitores de tela.

---

# Referências Visuais

O PM Sessions inspira-se em interfaces SaaS modernas.

Características observadas:

- dashboards minimalistas;
- calendários em destaque;
- cards elevados;
- poucas ações por tela;
- navegação lateral;
- drawers ao invés de modais sempre que possível.

# Fora de Escopo

Nesta versão não fazem parte:

- Light Theme;
- múltiplos temas;
- customização visual;
- white-label.

---

# Evolução

Este documento será atualizado sempre que:

- novos componentes forem criados;
- novos padrões forem definidos;
- alterações na identidade visual forem aprovadas.

Todo novo componente deverá respeitar este Brand Guide.
