# Logos

Esta pasta contém todos os arquivos oficiais da identidade visual da Pulse utilizados pelo PM Sessions.

## Organização

- icone - pulse_sop.svg
- logo toda branca - pulse-logo-allwhite.svg
- logo azul - pulse-logo-azul.svg
- logo branca pulse-logo-branca.svg

Sempre utilizar os arquivos desta pasta como fonte oficial da marca.

Novas versões devem substituir as existentes mantendo o histórico no Git.
