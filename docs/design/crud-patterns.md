# Toolbar

Sempre conter:

- Título
- Descrição
- Botão Primário

Exemplo

Participants

Gerencie os participantes

[ Novo ]

---

# Botão Primário

Sempre canto superior direito.

Nunca dentro da tabela.

---

# Botão Destrutivo

Sempre vermelho.

Sempre exige confirmação.

Nunca executar imediatamente.
