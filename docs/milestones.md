# Atualização

Os Milestones deverão ser atualizados sempre que:

- uma Sprint for concluída;
- um novo marco estratégico for criado;
- houver aprovação formal de uma entrega.

Não registrar tarefas operacionais neste documento.

As tarefas detalhadas pertencem ao Sprint Plan e às Specifications.
